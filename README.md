# 瞬間英作文の本

iPhone を横向きにして使う、紙の本のような瞬間英作文アプリ（PWA）。
左ページの和文を見て口に出し、右ページの英文をタップして答え合わせをする。それだけ。

公開先： https://cee-stars.github.io/SunkanBOOK/

## 使い方

| 操作 | できること |
|---|---|
| 左右にスワイプ | 見開きをめくる |
| 右ページの英文をタップ | その1文だけ表示（もう一度タップで隠れる。ページをめくると全部隠れる） |
| 右ページ右上の角をタップ | ズームして書き込み欄。日付は自動、ひとことを保存すると履歴に追加される |
| 左ページ左上の ❧ | 目次。章をタップでその章の先頭へ |
| アプリを開く | 前回のページから再開（しおり） |

右上の `✓3` は、その見開きに書き込みを保存した回数。

### ホーム画面に追加
Safari で開く → 共有 → 「ホーム画面に追加」。
2回目以降はオフラインでも開けます。

## 文の追加

### 方法1：アプリから追加する（iPhoneだけで完結）
目次 → **「＋ 文を追加する」** → 章を選び、和文と英文を入れて「追加」。
すぐ本に反映され、この端末に保存されます。新しい章も作れます。

その端末だけの追加なので、本体のデータに入れたいときは同じ画面の
**「JSONを書き出す」** を押すと全文のJSONがコピーされるので、
`data/sentences.json` に貼り替えてコミットしてください。

### 方法2：JSONを直接編集する
`data/sentences.json` を編集します（GitHub上で直接編集してもOK）。

```json
{
  "id": "ch2",
  "title": "第2章 不定詞",
  "template": "It is adj to V.",
  "sentences": [
    { "id": "ch2-001", "ja": "英語を話すのは楽しい。", "en": "It is fun to speak English." }
  ]
}
```

- `title` と `template` が左ページ上部の1行になります（`第2章 不定詞 ／ It is adj to V.`）
- 文は **5つごとに自動で1見開き** に割られます。端数はそのまま（最後の見開きが3文など）
- **`id` は一度つけたら変えないでください。** 書き込みの履歴をこのidで紐付けています
- 文は **章の末尾に足す** のが安全です。途中に挿入すると、それ以降の見開きの履歴がずれます
- ページ番号は目次を p.1–3 として **p.4 から自動採番**

## 保存されるもの（localStorage）

| キー | 中身 |
|---|---|
| `sb.notes` | 見開きごとの書き込み履歴（上書きせず追記） |
| `sb.bookmark` | しおり（最後に開いた見開き） |
| `sb.custom` | アプリから追加した文・章 |

Safari の履歴を消すと一緒に消えるので、大事な文は `data/sentences.json` に移してください。

## ファイル

```
index.html            本体（HTML + CSS + JS すべて）
data/sentences.json   文データ
manifest.webmanifest  PWA設定
sw.js                 オフライン用（ネット優先・失敗時キャッシュ）
icons/                アイコン
```

## GitHub Pages の公開手順

1. このブランチを `main` にマージ
2. Settings → Pages → Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
3. 数十秒後に https://cee-stars.github.io/SunkanBOOK/ が開く
